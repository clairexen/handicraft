## CARPET: Coarse Absolute and Relative Positional Encoding for Robust Long-Context Transformers

**CARPET** combines local RoPE-based relative positioning with a coarse absolute
sinusoidal phase channel, trained with structured positional dropout to improve
long-context disambiguation.

### Abstract

We propose **CARPET (Coarse Absolute and Relative Positional Encoding for
Transformers)**, a positional encoding scheme that separates **local relative
addressing** from **global positional disambiguation** in transformer
attention. Standard Rotary Position Embedding (RoPE) provides precise relative
offsets for nearby tokens but becomes unreliable for distinguishing similar
content across large contexts. CARPET augments RoPE with a **low-resolution
absolute sinusoidal phase channel** whose highest frequency corresponds to a
fixed locality scale (e.g., 32 tokens) and whose lower frequencies extend to
the full context length. These absolute features are injected both into the
**token input representation** and into a small **key/value subspace that does
not overlap with the RoPE dimensions**, allowing attention to query coarse
regions and preserve positional provenance while RoPE continues to encode local
relational geometry.  RoPE may optionally operate on a reduced ring size to
reinforce its role as a local relative encoding.

Training employs **structured positional dropout** to encourage the model to
utilize both mechanisms. RoPE frequency components overlapping with the
absolute regime are dropped with high probability, while the entire absolute
channel is occasionally removed for sequences that remain within the RoPE
locality window. The absolute phase origin is randomized during training, and
coherent spans of cached key/value states—representing short sequences with
meaningful internal neighborhood structure—may be placed at random positions on
the absolute ring. This ensures the model learns to address and revisit regions
across the entire positional range rather than relying only on the local
training window. Together these mechanisms create a robust dual-coordinate
system in which RoPE captures local structure while the absolute phase channel
provides coarse global addressing for long-context retrieval and
disambiguation.

CARPET is particularly well suited to **looped or recurrent transformer
architectures** that repeatedly refine their key/value state across multiple
passes. In such models, higher-layer reasoning from earlier passes can annotate
or modify the memory state that later tokens attend to. The presence of a
stable coarse absolute coordinate makes it easier for these annotations to
reference and revisit specific regions of the context. This illustrates a
broader advantage of looping architectures: they can propagate structural or
positional signals through internal representations rather than through
additional natural-language tokens. In contrast, chain-of-thought prompting
must express intermediate information linguistically and rely on lower layers
to reinterpret it. CARPET therefore highlights a setting where looping models
can transmit higher-level structural knowledge to future attention computations
in a way that token-level reasoning alone cannot.


### Parameterization

Let token *t* have

* **Relative position**: r_t (index within the current sequence window)
* **Absolute position**: a_t (position on the global absolute ring)

Key parameters:

* **S**: locality scale (tokens) where responsibility transitions from RoPE to absolute positioning
* **N_rel**: maximum relative scale represented by RoPE
* **N_abs**: maximum absolute context scale represented by the absolute channel
* **ρ > 1**: geometric ratio between adjacent frequency bands

The fastest RoPE band corresponds to period **2π tokens**, while the fastest absolute band corresponds to **2πS tokens**.

For a given maximum span **N** encoded with **d** sinusoidal dimensions, the
usual RoPE construction picks ρ = N^(2/d); here we instead treat **ρ** as
primary so that both relative and absolute ladders share the same ratio, and
solve for their dimensionalities based on **N_rel**, **N_abs**, and **S**.

In standard RoPE mode grce.py uses n_rope RoPE dimensions and N=n_pos. The
default value of n_rope is the full head dimension n_width / n_head.

In CARPET mode grce.py automatically splits n_rope into d_rel + d_abs <= n_rope.
So n_rope, despite it's name, stays the total number of head dimensions that
participate in positional encoding. Conceptionally we set S=30, N_rel=100, and
N_abs=n_pos, and then pick the smallest ρ > 1 so that d_rel + d_abs <= n_rope.


### Frequency Ladders

#### Relative (RoPE) scales

Relative token scales:

	λ_rel(j) = ρ^j   for   j = 0 … m_rel − 1   where   m_rel = 1 + ceil(log_ρ(N_rel))

Each scale corresponds to one sine/cosine pair.

Dimension count:

	d_rel = 2 m_rel

Relative phase:

	φ_rel(t, j) = r_t / λ_rel(j)

The wrap period in tokens is:

	T_rel(j) = 2π λ_rel(j)

#### Absolute scales

Absolute token scales start at S:

	λ_abs(k) = S ρ^k   for   k = 0 … m_abs − 1   where   m_abs = 1 + ceil(log_ρ(N_abs / S))

Dimension count:

	d_abs = 2 m_abs

Absolute phase:

	φ_abs(t, k) = a_t / λ_abs(k)

Wrap period:

	T_abs(k) = 2π λ_abs(k)


### RoPE Transformation

Let the query and key vectors contain a dedicated RoPE slice:

	q_rel , k_rel ∈ R^(d_rel)

Define the block‑diagonal rotation

	R_rel(r_t) = diag(Rot(φ_rel(t,0)), … , Rot(φ_rel(t,m_rel−1)))   where   Rot(θ) = [[cos θ, −sin θ], [sin θ, cos θ]]

Then

	q_rel_rot = R_rel(r_t) q_rel
	k_rel_rot = R_rel(r_t) k_rel

RoPE may intentionally operate with a small **N_rel**, restricting its effective ring size to a local neighborhood.


### Absolute Phase Channel

Absolute sinusoidal feature vector:

	z_abs(a_t) = [cos(φ_abs(t,0)), sin(φ_abs(t,0)), … , cos(φ_abs(t,m_abs−1)), sin(φ_abs(t,m_abs−1))]

This channel is used in three places.

#### Token input

Add the absolute phase contribution directly into the even slots of the tail of
the transformer width so that odd slots remain free for future schemes (e.g.,
SANe):

	h_t^(0)[-d_abs:][even indices] += z_abs(a_t)

Only the even elements receive positional signal; the odd elements stay
untouched and can be used by other mechanisms (see sane.txt for details
on the even/odd split).

#### Key/value absolute subspace

Reuse the same d_abs features by adding them to the last d_abs slots of the key
and value tensors (still within the existing n_width dimensions):

	K_t[:, :, -d_abs:] += z_abs(a_t)
	V_t[:, :, -d_abs:] += z_abs(a_t)

This reuses part of the head width without changing tensor ranks. The relative
RoPE slice remains at the beginning of Q/K, while the absolute information lives
at the end of K/V for easier disambiguation.

Final vectors conceptually become

	q_t = [ k_rel_rot | q_nonpos ]
	k_t = [ k_rel_rot | k_nonpos | k_abs_add ]
	v_t = [ v_nonpos | v_abs_add ]

This allows attention heads to query approximate regions and recover coarse positional provenance without introducing extra dimensions.


### Overlap Between Relative and Absolute Bands

Overlapping scales occur when

	λ_rel(j) ≥ S   and   λ_rel(j) ≤ N_rel

Let

	j_S = ceil(log_ρ(S))

Then the overlapping RoPE indices are

	J_overlap = { j_S , j_S + 1 , … , m_rel − 1 }

Number of overlapping frequency pairs:

	m_overlap = max(0, m_rel − j_S)

These are the lowest‑frequency RoPE bands.


### Structured Positional Dropout

#### RoPE dropout

During training, the overlapping RoPE bands are dropped with high probability.

This may be applied
* globally per batch
* independently per attention head

Operationally, the rotated components corresponding to indices in **J_overlap** are zeroed.

This removes long‑range relative cues and forces the model to rely on absolute addressing for distant disambiguation.

#### Absolute channel dropout

With lower probability, the entire absolute channel is dropped:

	z_abs(a_t) → 0

This is applied only when the sequence length fits within the RoPE locality window.

This ensures attention queries remain functional without absolute coordinates.


### Randomized Absolute Phase Origin

During training, the absolute coordinate system is randomly shifted:

	a_t = a_t* + δ

where

	δ ~ Uniform(0 , N_abs)

This prevents the model from associating specific semantics with fixed absolute phases.

The model can later be fine‑tuned with a fixed phase origin if desired.


### Randomized K/V Cache Placement

To ensure the model learns to use the full absolute ring even when training
sequences are short, training may include **coherent spans of cached key/value
states** placed at random absolute positions.

Each span corresponds to a small sequence segment with meaningful internal
neighborhood structure.

These spans occupy otherwise unused regions of the absolute ring, allowing the
model to practice addressing and revisiting distant memory regions.


### Summary

CARPET constructs a dual coordinate system:

* **RoPE** encodes precise local relative geometry
* **Absolute sinusoidal phase** provides coarse global addressing

Structured dropout and randomized phase placement prevent reliance on a single
positional mechanism and encourage robust long‑context retrieval and
disambiguation.

## CARPET2

The --use-carpet2 behavior in grce.py is as following: This is an experiment and
only defined for N=1024 and dims=64. And we assume S=32. (Using --use-carpet2
will produce an error for any other n_pos or n_rope.)

Let p be a position (token index). Its effective absolute position is:

	p_abs = p                                         abs(p) < N
	p_abs = sign(p)*(1.5*N - 0.5*N*N / abs(p))        otherwise

Let p1 and p2 be two positions (token indices). Their effective relative
position is:

	p_rel = p2-p1                                           abs(p2-p1) < S
	p_rel = sign(p2-p1)*(1.5*S - 0.5*S*S / abs(p2-p1))      otherwise

We allocate d_abs = d_rel = dims/2 dimensions to abs and rel addressing respectively.

We run RoPE on a N=32 ring with m_rel = d_rel/2 frequencies on the lowest d_rel
dimensions, except that we use p_rel as the effective relative position.

For the abs position on the higher d_abs dimensions we use the same m_rel
frequencies as for RoPE, but divided by 32. And instead of rotating pairs in Q we
simply add the absolute position to all K/V.

## CARPET3

The --use-carpet3 behavior in grce.py is as following: This is an experiment and
only defined for N=1024 and dims=64. And we assume S=32. (Using --use-carpet3
will produce an error for any other n_pos or n_rope.)

We use d_rel = 48 and d_abs = 16. We set S = N = 1024 for p_abs and p_rel.

The 48 RoPE dimensions simply implement RoPE on 24 frequencies with N=1024
(except for the use of p_rel instead of the actual relative position for
larger-than-N values).

The longest abs period relates to N in the same way the shortest RoPE
period relates to 1. The other abs frequencies spaced by the same geometric
factor as the RoPE frequencies.

CARPET3 also adds a per-K/V-head learned alpha and beta, that scale the
amplitude of the added abs position in K and V respectively.
